# PowerBI-Mobile-Sales-Dashboard

📊 Interactive Mobile Sales Dashboard built using Microsoft Power BI, DAX, Power Query to analyze sales performance, customer behavior, payment methods, and brand-wise sales insights. The dashboard enables users to explore business data through dynamic visualizations and interactive filters, supporting data-driven decision-making.


## 📈 Dashboard Features

- 📅 Monthly Sales Trend Analysis
- 📱 Sales by Mobile Model
- 💳 Transactions by Payment Method
- ⭐ Customer Ratings Analysis
- 📆 Sales by Day of Week
- 🏷 Brand-wise Sales Summary
- 🔍 Interactive Slicers for:
  - Month
  - Brand
  - Mobile Model
  - Payment Method
  - Day Name

 ## 📊 Business Insights

- Identified monthly sales trends and peak-performing months.
- Compared sales across different mobile models.
- Analyzed customer ratings to understand customer satisfaction.
- Evaluated payment method preferences.
- Measured brand performance using sales, quantity, and transaction metrics.
